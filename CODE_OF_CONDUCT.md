# Code of Conduct

## The short version

Be decent to people. Assume they are acting in good faith. Criticize code, not
the person who wrote it.

## Not acceptable

Harassment, personal attacks, insults, discriminatory or sexualized language,
publishing someone's private information, and sustained disruption of
discussion.

## Scope

This applies in every TorrenClou repository — issues, pull requests, code review
and commit messages — and anywhere someone is representing the project.

## Enforcement

Report a problem privately using GitHub's "Report abuse" on the content in
question, or by contacting an organization owner through their GitHub profile.
Reports are handled confidentially.

Maintainers may edit or remove comments, commits, issues and pull requests that
break these rules, and may block repeat offenders from the organization.
